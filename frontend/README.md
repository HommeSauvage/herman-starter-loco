# Frontend

A Vite + React 19 SPA that talks to the Loco API. Types for the API come from
Rust — `frontend/src/bindings/` is generated by `ts-rs` when the Rust test
suite runs. Never hand-edit that directory.

## Stack

- React 19 + React Router 8
- TanStack Query for server state
- Tailwind CSS v4 + shadcn/ui (`src/components/ui`)
- `ts-rs` bindings generated from `src/dtos/*` in the Rust crate

## Development

```sh
bun install
bun run dev       # http://localhost:5173, proxies /api to the Loco server
```

Set `PORT` if the API is not on 5150; the proxy reads the same variable.

## Build

```sh
bun run build     # writes dist/, which Loco serves at /
```

## Checks

```sh
bun run lint
bun run format:check
bun run typecheck
bun run build
```

Or run the whole repository gate: `./scripts/ci-check.sh` from the root.
